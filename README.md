## 1교시 — 개념 정리

### 1-1. 가격 비교에서 꼭 구분해야 할 세 가지 가격

| 용어 | 뜻 | 주의할 점 |
| --- | --- | --- |
| **실구매가** | 상품가 + 배송비 | 상품가만 보면 배송비 3,000원씩 손해 볼 수 있음 |
| **현금(조건부) 최저가** | 계좌이체 등 특정 결제수단 전용 가격 | 카드로는 그 가격에 못 삼 |
| **대형몰 카드 최저가** | G마켓·11번가 등에서 일반 카드결제로 살 수 있는 가격 | 조금 비싸지만 무이자 할부·구매 보호 |

> ⚠️ 다나와 1위 가격이 "현금 전용"인 경우가 많습니다. **조건부 가격을 일반가처럼 소개하면 비교 결과가 틀린 것**이 됩니다.

### 1-2. 노트북 GPU는 이름이 같아도 성능이 다르다 — TGP

노트북 그래픽카드는 **TGP(전력 한도)** 에 따라 성능이 크게 달라집니다.

| 제품 | 그래픽 | TGP |
| --- | --- | --- |
| ASUS TUF F16 | RTX 5060 | **115W** |
| 레노버 LOQ 15 | RTX 5060 | 100W |
| 에이서 니트로 V 16S | RTX 5060 | 70W |
| HP 오멘 15 | RTX 5060 | **55W** |

> 💡 **교훈:** "RTX 5060 노트북"이라는 이름만 보지 말고 **상세 사양의 TGP**를 꼭 확인하세요.

## 2교시 — 실습: 도구 준비 (그리고 문제 해결)

### 2-1. 자료 찾기

```bash
find ~ -maxdepth 4 -iname '*kskill*'     # k-skill 위치 찾기
cat ~/Downloads/docx/.env                # Firecrawl 키 확인 → 키 없음 (경로 문자열만 있음)
git clone --depth 1 https://github.com/NomaDamas/k-skill
```

### 2-2. ⚠️ 문제 1: `npx`가 없다

스킬 공식 실행 방법은 `npx -y @nomadamas/k-skill@0 instruct danawa-price-search` 입니다.

```
/usr/bin/bash: line 1: npx: command not found
```

**해결:** 스킬 폴더 안의 원본 설명서(`instruction.md`)와 Python 스크립트(`scripts/danawa_search.py`)를 **직접** 사용했습니다.

```bash
python -m venv venv
venv/Scripts/python -m pip install beautifulsoup4     # 스크립트가 요구하는 라이브러리
venv/Scripts/python k-skill/danawa-price-search/scripts/danawa_search.py search "RTX 5060" --limit 5
```

> 💡 2주차 1교시 노트와 같은 교훈입니다. **자동 도구가 안 되면, 도구가 실제로 하는 일을 직접 하면 됩니다.**

### 2-3. ⚠️ 문제 2: 한글이 깨진다

```
"title": "COLORFUL ������ RTX 5060 Ti ..."
```

**원인:** `python -I`(격리 모드)는 `PYTHONIOENCODING` 같은 환경변수를 **무시**합니다.
**해결:** 환경변수 대신 **`-X utf8` 옵션**을 쓰고, 한글 검색어는 명령줄 인자 대신 **UTF-8 파일**로 넘겼습니다.

```bash
venv/Scripts/python -I -X utf8 survey.py queries.txt
```

### 2-4. 스킬 명령 3가지

| 명령 | 하는 일 | 예시 |
| --- | --- | --- |
| `search` | 검색어로 상품 후보와 `pcode` 찾기 | `search "라이젠5 5600"` |
| `offers` | 한 상품의 판매처별 가격 (실구매가 오름차순) | `offers 16741211` |
| `compare` | 검색 + 오퍼를 한 번에 | `compare "RTX 5060"` |

## 5교시 — 실습: GitHub Pages로 배포

```bash
git init -b main
git add .
git commit -m "RTX 5060 게이밍 PC 견적 최저가 페이지"
gh repo create DIDIDIP/pc-quote-lowest-price --public --source=. --push
gh api -X POST repos/DIDIDIP/pc-quote-lowest-price/pages \
  -f "source[branch]=main" -f "source[path]=/"
```

| 단계 | 의미 |
| --- | --- |
| `--public` | **무료 계정에서 Pages를 쓰려면 공개 저장소**여야 함 |
| `gh api .../pages` | `main` 브랜치 루트(`/`)를 웹사이트로 공개 |
| 상태 확인 | `building` → `built`, `curl` 응답 `200`이면 배포 완료 (약 40초) |

> ⚠️ 공개 저장소는 **누구나 볼 수 있고 검색에 노출**될 수 있습니다. 비밀 정보(API 키 등)는 절대 올리지 마세요.

## 📝 핵심 요약

1. 쇼핑 스킬은 `npx`가 없어도 **스크립트를 직접 실행**하면 된다 (`python -I -X utf8`)
2. 가격은 항상 **배송비 포함 실구매가**로, **결제조건(현금/카드)** 을 구분해서 비교한다
3. 2026년 하반기에는 메모리 값이 비싸서 **DDR4(AM4)** 가 가성비 플랫폼이다
4. 판매처만 대형몰로 바꾸는 비용은 작고, **제품 업그레이드**가 가격을 크게 바꾼다
5. 노트북은 **TGP**, 스마트폰은 **자급제/해외구매/색상**을 꼭 확인한다
6. 결과를 HTML로 만들고 `gh repo create` + Pages API로 **한 번에 배포**할 수 있다
